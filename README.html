TDD with TypeScript: Prime Number Calculator

A small TypeScript project built with Test-Driven Development (TDD). The project implements a prime number calculator, written step by step using the red, green, refactor cycle.

Features

  • isPrime(n): returns true if n is a prime number, otherwise false.
  • listPrimesInRange(start, end): returns an array of all prime numbers in the given range (inclusive).

Tech Stack

  • TypeScript
  • Jest
  • ts-jest

Getting Started

Prerequisites

  • Node.js 18 or newer
  • npm

Installation

git clone <repository-url>
cd TDDwithTypeScript
npm install

Available Scripts

Command Description
npm test Runs all the tests once.
npx jest --coverage Runs the tests and generates a coverage report in the coverage/ folder.

Project Structure

TDDwithTypeScript/ ├── src/ │ ├── primeCalculator.ts # isPrime and listPrimesInRange │ └── tests/ │ └── tdd/ │ └── prime.test.ts # Unit tests ├── jest.config.js # Jest configuration ├── tsconfig.json # TypeScript configuration ├── package.json └── README.md

TDD Cycles

  1. Cycle 1: isPrime returns false for numbers less than 2.
  2. Cycle 2: isPrime identifies non-prime numbers, using a loop up to the square root of n.
  3. Cycle 3: listPrimesInRange returns the primes within a range, reusing isPrime.
